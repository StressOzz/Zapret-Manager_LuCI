## Установка

В **SSH**

```
sh <(wget -qO - https://raw.githubusercontent.com/StressOzz/Zapret-Manager/main/ZapretManager_LuCI.sh)
```

После установки в LuCI появляется раздел **Zapret Manager**.

### Zapret

Установка, обновление, удаление и управление состоянием Zapret.

В менеджере можно:

- установить актуальную версию;
- обновить уже установленный Zapret;
- запустить и остановить службу;
- выбрать стратегию;
- работать со стратегиями v и Flowseal;
- отдельно настраивать YouTube;
- управлять Discord;
- использовать игровые настройки;
- проверять состояние и подключение;
- работать с исключениями.

При установке версия Zapret определяется по последнему релизу `remittor/zapret-openwrt`. Если определить её не удалось, используется резервная версия, заданная в менеджере.

## Стратегии

Стратегии не зашиты только в интерфейс.

Менеджер формирует параметры для Zapret и позволяет переключаться между вариантами без ручного редактирования `NFQWS_OPT`.

Отдельно поддерживаются:

- стратегии v;
- стратегии Flowseal;
- YouTube;
- Discord;
- игровые настройки.

Есть отдельная страница тестирования.

Тест запускается в фоне, поэтому закрытие или переключение страницы LuCI его не прерывает. После завершения исходная конфигурация возвращается обратно.

Тест показывает результаты для разных вариантов. Самый подходящий вариант не применяется автоматически — его можно выбрать и применить вручную.

Это сделано специально: результат теста и изменение рабочей конфигурации — разные действия.

## Zapret2


Для Zapret2 менеджер использует отдельные файлы конфигурации и custom-скрипты.

На текущей версии установщик Zapret2 ограничивает установку архитектурой:

```text
aarch64_cortex-a53
```

Zapret и Zapret2 считаются несовместимыми при обычной установке. Менеджер проверяет наличие второго варианта перед установкой и не пытается молча поставить оба.

## Hosts

Есть отдельный раздел для работы с `/etc/hosts`.

Доступны:

- просмотр состояния;
- включение и отключение обработки;
- замена hosts-набора;
- восстановление;
- просмотр содержимого;
- сохранение изменений.

## DoH

Менеджер содержит управление DoH:

- проверка состояния;
- установка;
- удаление;
- выбор провайдера.

## Mihomo

Mihomo не является частью Zapret, но управление им вынесено в тот же интерфейс, поскольку на OpenWrt эти инструменты часто используются вместе.

Через LuCI доступны:

- состояние Mihomo;
- запуск и остановка;
- просмотр и изменение конфигурации;
- подписка;
- MagiTrickle;
- автоматический перезапуск;
- UI;
- WARP;
- интеграция WARP;
- интеграция VPN подписки;
- конфигурация WARP.

## Фоновые операции

Долгие действия не выполняются непосредственно в HTTP-запросе LuCI.

Это касается, в частности:

- установки;
- обновления;
- удаления;
- тестирования стратегий.

Поэтому закрытие страницы браузера не означает автоматическую остановку операции.

## Совместимость

Проект рассчитан на OpenWrt с пакетным менеджером `opkg` или `apk`.

Менеджер сам определяет используемый пакетный менеджер и использует соответствующие команды.

## Удаление

Менеджер содержит отдельное удаление панели из LuCI.

Удаление панели не должно рассматриваться как удаление самого Zapret.

Zapret, Zapret2, Mihomo и другие компоненты управляются отдельно.

Это важно: панель — интерфейс управления, а не замена службам, которыми она управляет.

## Откуда берутся компоненты

Zapret Manager использует внешние проекты и источники, а не пытается быть форком каждого инструмента.

В частности:

- Zapret — `remittor/zapret-openwrt`
- Flowseal — `Flowseal/zapret-discord-youtube`
- дополнительные файлы и настройки — репозиторий Zapret Manager

Менеджер только связывает эти компоненты с интерфейсом OpenWrt.

## Зачем он вообще нужен

Если всё устраивает через SSH и несколько команд — Zapret Manager не обязателен.

Он появился для другой ситуации: когда на роутере уже несколько связанных инструментов, конфигов и стратегий, а постоянно помнить команды, пути и порядок действий просто неудобно.

Вместо:

```text
SSH
  -> проверить пакет
  -> найти конфиг
  -> скачать файл
  -> изменить UCI
  -> перезапустить службу
  -> проверить результат
```

получается:

```text
LuCI
  -> Zapret Manager
  -> нужное действие
```

Без попытки превратить OpenWrt в отдельную операционную систему внутри операционной системы.
